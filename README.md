# 폐쇄런 · Closed Ward Run 2.0

ZUKU JUMP용 3D 도주 액션. 최대 100스테이지의 도로를 돌파하세요.

- **100스테이지**: 구간당 360m, 10종 도로 테마와 상승하는 속도·교통 밀도. 100구간을 통과하면 탈출 엔딩.
- **분기**: 구간 끝에서 왼쪽/오른쪽 차선을 선택하면 다음 경로가 바뀝니다. 가운데로 진입하면 충돌 후 왼쪽으로 이동합니다.
- **돌진**: SHIFT 또는 돌진 버튼. 충전 100%를 소비해 다음 스테이지로 이동하고 1.1초 동안 충격을 무시합니다. 초당 3.5% 충전.
- **아이템**: 분홍색 상자를 획득하고 E 또는 아이템 버튼으로 사용합니다. 근거리 파괴 망치, 같은 차선 전방 투척 폭탄, 10초 경찰 EMP, 1회 보호막, 구급약, 부스트 충전의 6종입니다.
- **추돌·폭발**: 차량 사고에는 폭발과 카메라 흔들림이 발생합니다. 반경 6m 안의 플레이어도 피해를 입으며 수배가 증가합니다. 충격 무적 시간 동안 중복 피해를 받지 않습니다.
- **도로 특성**: 고속도로 가속, 자동차 전용도로 경찰 2배, 빙판의 느린 차선 전환, 침수 구간 감속, 공사장·검문소의 점프 장애물. 기존 급커브·테이저·헬기·음주/과속/역주행 이벤트도 유지됩니다.

## 조작

Enter 시작 · ←/→ 또는 A/D 차선 이동 · Space/↑/W 점프 · SHIFT 돌진 · E 아이템 · ESC 일시정지. 모바일은 화면 버튼과 스와이프를 지원합니다.

## ZUKU Cloud와 2인 멀티플레이

JUMP에서 **ZUKU 계정으로 연결**하면 호스트가 로그인 세션을 사용합니다. 게임 iframe은 계정 토큰을 받지 않습니다. Cloud 프로젝트는 서버가 현재 게임 콘텐츠에 연결된 프로젝트로 결정합니다.

방 만들기 → 초대 코드 공유 → 상대 참가 → 방장의 **함께 출발**. 두 플레이어는 공통 시드·서버 카운트다운으로 출발하며, 500ms 간격으로 위치·거리를 공유하고 가까운 상대는 3D 캐릭터로 표시합니다. 각자의 장애물 판정으로 거리를 겨루는 친선 레이스입니다. 서버 권위 물리 동기화나 보상용 부정행위 검증은 제공하지 않습니다. 방장은 나가면 방이 닫히고, 연결이 90초 끊긴 참가자는 만료됩니다.

종료 시 개인 최고점을 원자적으로 갱신하고 세이브를 저장합니다. 랭킹은 50명씩 추가 조회할 수 있습니다. 실패는 화면에 표시하며 수동 재시도가 가능합니다. 랭킹은 **클라이언트 제출 기록**입니다.

웹 단독 실행에서는 콘텐츠 ID와 현재 사용자의 세션 토큰을 직접 입력할 수 있습니다. 토큰은 메모리에서만 사용됩니다. 일반 사용자는 JUMP 호스트에서 계정 연결을 이용하세요. 익명/미연결 상태에서도 싱글플레이는 가능합니다.

공통 클라이언트는 `@zuku/game-kit/cloud`이며, 이 저장소의 `app/vendor/game-cloud.js`는 동일 소스의 복사본입니다. API 계약은 `docs-source/game-cloud.md`에 정리되어 있습니다. 플랫폼의 공통 Cloud 런타임과 호스트 브리지가 필요합니다.

## 개발과 패키징

Node.js 22.13+에서 `npm ci` 실행 후:

```sh
npm run dev
npm test
npm run typecheck
npm run build:pages
npm run build:zwf
npm run verify:zwf
```

Pages 산출물은 `docs/`, JUMP 패키지는 `dist/closed-ward-run.zwf`입니다. ZWF는 CRC로 검증되는 `html5-sandbox/1` WEBZ 패키지이며 네트워크는 차단한 채 허용된 호스트 메시지로 Cloud를 사용합니다. 기존 `zwf-v*` 태그 릴리스 워크플로를 유지합니다.

게임: `app/runner.ts` · 스테이지/맵: `app/stages.ts` · Cloud UI: `app/CloudPanel.tsx` · 규칙: `app/rules.ts`.
