# 폐쇄런 · Closed Ward Run

멘헤라짱의 심야 3D 도주 액션. 멈추면 입원이다.

플레이: https://niseullent.github.io/closed-ward-run/

## 조작

- Enter 또는 도망 시작: 게임 시작
- ← / → 또는 A / D: 차선 이동
- ESC / Space: 일시 정지 및 재개
- 모바일: 좌우 버튼 또는 스와이프
- 스피커 버튼: BGM 및 효과음 음소거

자동으로 달리며 차량을 피합니다. 도주 거리가 늘수록 속도가 올라갑니다. 충돌할 때마다 수배 별과 추격 경찰이 하나씩 늘어납니다. 90초가 지나고 별이 1개 이상이면 경찰이 서서 테이저건을 발사하며, `Space`/`↑` 점프로 피할 수 있습니다. 120초가 지나고 별이 3개 이상이면 계엄령이 발동하고 헬기가 나타납니다. 헬기와 추돌하면 공군 헬기로 입원합니다. 네 번째 일반 충돌은 기존처럼 들것에 실려 구급차로 들어가는 연출 후 게임오버입니다.

게임 중 우측 상단의 전방 감시 2D HUD에서 차·경찰·테이저·헬기의 위치를 확인할 수 있습니다. `←` / `→` 또는 `A` / `D`로 차선을 바꾸고, `Space` / `↑` / `W`로 점프합니다. `ESC`는 일시 정지입니다.

맵은 600m마다 구역이 바뀝니다: 불야성 도심 → 주택가 골목 → 심야 고속도로 → 병원 구역. 구역마다 안개·조명 색, 차량 간격·속도, 기본 속도가 다르고, 네 바퀴를 한 바퀴 돌 때마다 차량 간격이 더 촘촘해집니다. 구역 진입 시 배너와 도로 간판에 표시됩니다.

BGM: `public/audio`의 mp3를 순서대로 돌아가며 재생합니다(현재 `song1.mp3` → `closed-run-bgm.mp3` 무한 반복). 새 mp3를 폴더에 넣고 `TRACK_URLS`에 추가하면 됩니다. 정지 및 음소거에 연동합니다.

## 개발

Node.js 22.13 이상에서 `npm ci` 후 `npm run dev`로 실행합니다.

`npm run build:pages`는 GitHub Pages용 정적 파일을 `docs/`에 만듭니다. Pages의 배포 소스는 `main` 브랜치의 `/docs`입니다. 변경 후 빌드 결과도 함께 커밋합니다.

검사: `node --test tests/rules.test.mjs`, `npx tsc --noEmit`.

게임 로직과 3D 씬은 `app/runner.ts`, 충돌 규칙은 `app/rules.ts`, 캐릭터 모델은 `app/characters.ts`에 있습니다. UI는 `app/page.tsx`와 `app/globals.css`입니다.
