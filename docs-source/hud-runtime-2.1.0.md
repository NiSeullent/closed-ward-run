# v2.1.1 · 플레이 화면과 런타임

- 거리·스테이지는 상단, 이동·돌진·아이템은 하단에 배치합니다. 활성 게임의 캔버스는 이 두 영역 사이에 표시됩니다.
- 체력 등 보조 표시의 불투명도는 68%, 일시적인 알림은 78%로 낮췄습니다. 전방 지도는 설정에서 선택적으로 켭니다.
- Pretendard 가변 폰트와 원본 OFL을 패키지에 포함합니다.
- ZWF 빌드 및 JUMP 세션에서는 외곽 로고·푸터·상시 Cloud 패널을 제거하고 게임 프레임이 뷰포트를 채웁니다. 별도 웹 페이지는 로고와 키 안내를 유지합니다.
- 랭킹·멀티플레이는 각각 독립 버튼으로 여는 창입니다. 창은 포커스를 가두고 게임 키 입력을 차단합니다. 실행 중 열면 정지하고 닫으면 재개하며, 수동 정지 상태는 그대로 유지합니다.
- 창의 표시 여부와 Cloud 수명은 분리되어 방 동기화와 종료 시 저장이 계속됩니다. 공동 출발 시 멀티플레이 창이 닫힙니다.
- 전체 화면에서도 랭킹 창을 가운데 표시하도록 기본 CSS의 여백 초기화를 보완했습니다.

검증: 단위 테스트 16개, TypeScript, Pages/ZWF 빌드와 패키지 CRC 검증. 900×560, 390×844, 390×240, 844×390, 320×240에서 HUD·버튼 경계, 런타임 외곽 요소 제거와 스크롤 방지, 폰트 로드, 창 열기/닫기·키 입력 격리·수동 정지를 확인했습니다. 실제 DB를 사용한 두 브라우저 검사 8개(공동 출발·상대·승패·실패한 기록 저장 재시도·같은 랭킹·퇴장)를 통과했습니다. 빌드된 런타임을 쿼리 없이 열어 외곽 요소 제거와 돌진·랭킹 창을 확인했습니다.
