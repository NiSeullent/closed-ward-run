# 요청 항목별 완료 검증 · v2.0.1

검증 대상은 실제 `app/runner.ts`와 공개 JUMP에 등록한 패키지입니다. 수치 함수 테스트만으로 게임 동작을 대신하지 않았습니다. 테스트 전용 Vite 변환으로 엔진 내부에 초기 조건을 주입하고 실제 애니메이션·충돌·아이템·장면 코드를 실행했습니다. 테스트 도구는 운영 패키지에 포함되지 않습니다.

| 요청 | 구현과 확인 근거 |
|---|---|
| 1. ZUKU 멀티플레이·클라우드 랭킹 | 기존 JUMP 콘텐츠에 nyase의 활성 Cloud 프로젝트 연결. 실제 두 계정/브라우저에서 방 참가·공통 출발·상대 표시·승패·개인 점수 저장·같은 랭킹 조회를 확인. |
| 2. 맵 다양화·스테이지·난이도 | 10종 도로의 독립 구조물과 색·속도·조향·경찰/장애물 차이. 엔진으로 100개 스테이지 진입을 모두 실행하고 같은 맵의 후기 스테이지에서 실제 속도 상승을 확인. |
| 3. 최대 100·돌진 스킵 | 1~100 경계를 모두 엔진으로 통과. 36,000m에서 종료·진행률 100%·101스테이지 없음. 돌진의 구간 이동·충전 소모·무적·재충전을 확인. |
| 4. 파괴·투척·경찰 파괴 아이템 | 6종 아이템을 물리적으로 획득. 망치의 차량/장애물 파괴, 이동하는 폭탄의 명중, 경찰 EMP의 제거 이펙트/지원 병력 지연, 보호막 1회 흡수·치료·충전 효과를 검증. |
| 5. 차량 추돌·폭발·범위 피해 | 일반·과속·역주행·음주 차량의 플레이어 충돌과 차량 간 사고를 실제 엔진으로 검증. 폭발이 발생하고 반경 6m 내 플레이어의 체력/수배가 변하며, 범위 밖과 충격 무적 중에는 추가 피해가 없음. |
| 6. 도로별 기믹·경찰 2배·좌우 분기 | 자동차 전용도로의 실제 경찰 모델 수 2→4, 고속도로/침수 속도 차이, 빙판 조향 지연을 검증. 좌우 선택이 서로 다른 맵으로 이어지고 중앙은 피해 1회 후 왼쪽으로 이동. 표지판이 양쪽 목적지를 안내. |
| 7. 추가 기믹 | 점프로 검문/공사 장애물 회피, 보호막·구급약, 기존 급커브·테이저·헬기·특수 차량 유지. 실제 점프/지상 충돌과 4회 피해 후 포획→종료를 확인. |
| 8. 멀티플레이 | 2인 친선 레이스의 방 생성/참가/동시 출발/진행 거리 차이/상대 캐릭터/최종 승패/퇴장 검증. 같은 라운드 상태만 표시. 서버는 공통 2~8인 방을 지원하며 이 게임은 2인으로 사용. |
| 9. ZUKU Cloud 제작 | 공통 Game Cloud SDK·콘텐츠 범위 호스트 브리지 사용. 계정 토큰은 게임에 전달되지 않음. ZWF 샌드박스·CRC·테스트 코드 제외 검증. nyase 연결과 패키지 실제 제공 파일의 해시 일치 확인. |
