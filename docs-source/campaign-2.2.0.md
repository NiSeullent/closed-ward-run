# 폐쇄런 v2.2.0 · 400단계 세계 캠페인과 자동 연결

49단계 판문점, 50–79단계 북한, 55단계 인민군 사령관과 70단계 김정은 보스전을 거쳐 중국·러시아로 이어집니다. 발트 3국, 폴란드·체코·오스트리아·이탈리아·그리스·튀르키예·키프로스·이집트·수단·에티오피아·지부티를 지나 360–400단계 소말리아까지 19개 연속 지역을 제공합니다. 페리 구간은 갑판·항구 맵으로 연결합니다. 보스전 중 거리는 고정되며 돌진으로 전투를 넘길 수 없습니다.

400단계의 마지막 360m를 통과하면 정신병원 컷씬이 시작됩니다. 간호사가 환자에게 “퇴원입니다”라고 말하고 크레딧이 이어집니다. 건너뛰기는 먼저 크레딧으로, 다음에는 결과 화면으로 이동합니다. 이후 선택적으로 401단계부터 무한모드를 시작합니다.

16종의 예고형 이벤트는 점프·돌진·안전 차선·박자·낮은 천장·순간이동·보상 구간으로 구분됩니다. 소말리아는 2중, 385단계부터 3중 조합입니다. 2.4초 예고와 항상 안전한 초록 차선, 이벤트당 최대 1회 피해를 보장합니다. 이벤트 중 기존 차량/공격을 억제하며 기본 속도와 차량 밀도를 무한히 올리지 않습니다.

랭킹·세이브는 스토리와 무한모드에 각각 `closed-run-story-v4` / `closed-run-endless-v4`, `closed-run-v4-story` / `closed-run-v4-endless`를 사용합니다. 이전 v2 기록은 삭제하지 않습니다. 사이트 로그인과 최초 계정·게임별 동의를 재사용하며, 로그아웃·계정 전환 시 이전 계정의 기록과 방 상태를 지웁니다. 이미 시작된 플레이는 새 계정으로 저장하지 않습니다.

음악은 같은 페이즈에서 유지합니다. 1–14: song1, 15–29: p2, 30–49: p3, 50 이상·보스·무한: bossfinal. 사용자 제공 MP3 원본을 번들에 포함합니다. p2 124.08초, p3 220.032초, bossfinal 137.64초. 현재 페이즈 곡이 끝나면 같은 곡을 다시 재생합니다.

검증: TypeScript와 단위 검사 30개, 실제 Chromium 엔진 검사 24개(400개 맵, 두 보스, 복합 이벤트의 예고·안전 차선·점프·포털, 경계 통과, 병원·크레딧·무한모드, 기존 차량·아이템·음악)를 통과했습니다. PC/모바일 병원 컷씬, 크레딧, 국가별 맵과 복합 이벤트 HUD를 확인했습니다.

플랫폼의 공통 전체화면은 네이티브 화면의 높이 제한을 해제하고 미지원/거절 시 화면 전체를 채우는 대체 모드를 제공합니다. 런타임 버튼도 호스트 화면을 확대하며 사이트 동의창과 종료 버튼에 접근할 수 있습니다. 네이티브 진입·종료, 모바일 대체 모드와 플레이 상태를 보존하는 종료를 브라우저에서 확인했습니다.
